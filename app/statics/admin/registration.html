点击“启动注册”后，按下方阈值定时检查普通号池和 Build 号池。任一池未达标时，每次只注册 1 个账号，再重新检查。
比较两个账号池的可用数量的间隔。保存后会立即唤醒正在轮询的补号任务。
普通池仅统计状态为正常的账号数量；限流、异常、禁用不计入。填 0 表示不检查该池。
Build 池仅统计状态为正常的账号数量；限流、禁用不计入。需要启用 CPA Auth 导出和自动导入 Build 池。填 0 表示不检查该池。
将使用现有账号管理接口导入，不会覆盖已存在账号。

支持 HTTP/HTTPS/SOCKS5；带账号密码的 SOCKS5 会自动通过本地安全转发连接。
CPA / OIDC 导出（Grok 4.5）
使用 SSO 优先走协议 device-flow mint OIDC；协议失败时才回退浏览器流程。默认关闭，不影响现有 SSO 入池。
