图像与视频接口

使用 OpenAI 兼容接口调用 Grok Imagine 图像生成、参考图编辑及视频生成能力。示例只提供 cURL 和 Python requests。

使用方式：复制示例后，将 YOUR_API_KEY 替换为配置管理中创建的 API Key。页面会将示例中的 {{BASE_URL}} 自动替换为上面的地址。

身份验证

除媒体文件查询接口外，所有业务接口都需要在 HTTP 请求头中携带 API Key。

Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
GET

/v1/models

返回当前实例已启用、可调用的模型。请以该接口实际返回的模型 ID 为准。

curl "{{BASE_URL}}/v1/models" \
  -H "Authorization: Bearer YOUR_API_KEY"
import requests

response = requests.get(
    "{{BASE_URL}}/v1/models",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    timeout=60,
)
response.raise_for_status()
print(response.json())

成功响应示例

{
  "object": "list",
  "data": [
    {"id": "grok-imagine-image-lite", "object": "model"},
    {"id": "grok-video", "object": "model"}
  ]
}
POST

/v1/images/generations

根据文字提示词生成图片。请求体必须为 JSON。

字段类型说明
modelstring必填。图像模型 ID，例如 grok-imagine-image-lite。
promptstring必填。图片描述。
ninteger可选，生成数量，默认 1。
sizestring可选，默认 1024x1024。
response_formatstringurl 或 b64_json，默认 url。
curl "{{BASE_URL}}/v1/images/generations" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "grok-imagine-image-lite",
    "prompt": "一只戴着宇航员头盔的橘猫，电影感光影",
    "n": 1,
    "size": "1024x1024",
    "response_format": "url"
  }'
import requests

payload = {
    "model": "grok-imagine-image-lite",
    "prompt": "一只戴着宇航员头盔的橘猫，电影感光影",
    "n": 1,
    "size": "1024x1024",
    "response_format": "url",
}
response = requests.post(
    "{{BASE_URL}}/v1/images/generations",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json=payload,
    timeout=180,
)
response.raise_for_status()
print(response.json())

成功响应示例（response_format=url）

{
  "created": 1787126400,
  "data": [
    {"url": "{{BASE_URL}}/v1/files/image?id=3d1d5d4d-2c8f-4c7f-a5f6-5d95c70c9e01"}
  ]
}
POST

/v1/images/edits

上传一张或多张参考图，并按提示词生成编辑后的图片。请求必须使用 multipart/form-data。

注意：文件字段名必须为 image[]。当前不支持 mask；请确保声明的 MIME 类型与文件真实格式一致。
字段类型说明
modelstring必填。图像编辑模型 ID。
promptstring必填。编辑要求。
image[]file必填。参考图片，可重复传入。
ninteger可选，默认 1。
sizestring可选，默认 1024x1024。
response_formatstring可选：url 或 b64_json。
curl "{{BASE_URL}}/v1/images/edits" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=grok-imagine-image-lite" \
  -F "prompt=将人物改为在海边散步的水彩插画" \
  -F "image[]=@./reference.jpg;type=image/jpeg" \
  -F "n=1" \
  -F "size=1024x1024" \
  -F "response_format=url"
import requests

with open("reference.jpg", "rb") as image_file:
    response = requests.post(
        "{{BASE_URL}}/v1/images/edits",
        headers={"Authorization": "Bearer YOUR_API_KEY"},
        data={
            "model": "grok-imagine-image-lite",
            "prompt": "将人物改为在海边散步的水彩插画",
            "n": "1", "size": "1024x1024", "response_format": "url",
        },
        files={"image[]": ("reference.jpg", image_file, "image/jpeg")},
        timeout=180,
    )
response.raise_for_status()
print(response.json())

成功响应示例

{"created": 1787126400, "data": [{"url": "{{BASE_URL}}/v1/files/image?id=2a80cb8b-11c2-4a6a-a00f-925d2e3dbf80"}]}
POST

/v1/videos

根据文字提示词创建异步视频任务。请求必须使用 multipart/form-data，创建成功后请轮询任务状态。

字段类型说明
modelstring必填。视频模型 ID，例如 grok-video。
promptstring必填。视频描述。
secondsinteger可选。支持 6、10、12、16、20，默认 6。
sizestring可选。720x1280、1280x720、1024x1024、1024x1792、1792x1024。
resolution_namestring可选：480p 或 720p。
presetstring可选：fun、normal、spicy、custom。
curl "{{BASE_URL}}/v1/videos" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=grok-video" \
  -F "prompt=一艘飞船穿过木星云层，电影级镜头运动" \
  -F "seconds=6" \
  -F "size=720x1280" \
  -F "resolution_name=480p" \
  -F "preset=normal"
import requests

response = requests.post(
    "{{BASE_URL}}/v1/videos",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    data={
        "model": "grok-video",
        "prompt": "一艘飞船穿过木星云层，电影级镜头运动",
        "seconds": "6", "size": "720x1280",
        "resolution_name": "480p", "preset": "normal",
    },
    timeout=90,
)
response.raise_for_status()
print(response.json())

  "status": "queued",

/v1/videos（图生视频）

图生视频与文生视频使用同一个接口；仅需额外提交参考图字段。

注意：参考图字段名为 input_reference[]，不是 image[]、image_urls 或 reference_images。最多会使用前 7 张参考图。
curl "{{BASE_URL}}/v1/videos" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "model=grok-video" \
  -F "prompt=让画面中的人物自然转身并向镜头挥手" \
  -F "seconds=6" \
  -F "size=720x1280" \
  -F "input_reference[]=@./reference.jpg;type=image/jpeg"
import requests

with open("reference.jpg", "rb") as image_file:
    response = requests.post(
        "{{BASE_URL}}/v1/videos",
        headers={"Authorization": "Bearer YOUR_API_KEY"},
        data={
            "model": "grok-video",
            "prompt": "让画面中的人物自然转身并向镜头挥手",
            "seconds": "6", "size": "720x1280",
        },
        files={
            "input_reference[]": ("reference.jpg", image_file, "image/jpeg"),
        },
        timeout=90,
    )
response.raise_for_status()
print(response.json())

创建任务成功响应示例

{"id": "video_619f138b4d6841449a1c39b6b75617f0", "object": "video", "status": "queued", "model": "grok-video"}
GET

/v1/videos/{video_id}

查询异步视频任务状态。状态为 completed 后，使用 下载媒体接口获取 MP4。

curl "{{BASE_URL}}/v1/videos/video_619f138b4d6841449a1c39b6b75617f0" \
  -H "Authorization: Bearer YOUR_API_KEY"
import requests

video_id = "video_619f138b4d6841449a1c39b6b75617f0"
response = requests.get(
    f"{{BASE_URL}}/v1/videos/{video_id}",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    timeout=60,
)
response.raise_for_status()
print(response.json())

响应示例：生成中

{"id": "video_619f138b4d6841449a1c39b6b75617f0", "object": "video", "status": "in_progress", "progress": 42}

响应示例：已完成

{
  "id": "video_619f138b4d6841449a1c39b6b75617f0",
  "object": "video",
  "status": "completed",
  "content_url": "{{BASE_URL}}/v1/videos/video_619f138b4d6841449a1c39b6b75617f0/content"
}

响应示例：失败

{"id": "video_619f138b4d6841449a1c39b6b75617f0", "object": "video", "status": "failed", "error": {"message": "上游视频任务失败"}}

下载媒体

图片 URL 会直接出现在图像接口成功响应中；视频任务完成后，通过视频内容接口下载。

GET

/v1/videos/{video_id}/content

curl -L "{{BASE_URL}}/v1/videos/video_619f138b4d6841449a1c39b6b75617f0/content" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -o result.mp4
import requests

response = requests.get(
    "{{BASE_URL}}/v1/videos/video_619f138b4d6841449a1c39b6b75617f0/content",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    timeout=180,
)
response.raise_for_status()
with open("result.mp4", "wb") as file:
    file.write(response.content)

也可使用本地缓存文件接口：GET /v1/files/image?id=图片ID 与 GET /v1/files/video?id=video_<uuid>。文件 ID 必须来自本服务返回的结果。

常见错误

状态码含义与处理
400参数或文件字段不符合要求。图生图请使用 image[]；图生视频请使用 input_reference[]。
401未携带 API Key 或 API Key 无效。
404视频/媒体 ID 不存在，或使用了错误的接口地址。
429上游账号处于限流或额度不足状态。服务会按账号调度策略重试或切换账号。
500 / 502上游请求或网络链路异常。请记录响应中的 error.message，稍后重试。

错误响应格式示例

{
  "error": {
    "message": "Invalid file ID",
    "type": "invalid_request_error",
    "code": "invalid_value",
    "param": "id"
  }
}
